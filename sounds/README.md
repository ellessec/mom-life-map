# 音效

把声音文件放进这个文件夹，然后在 `js/data.js` 的 `sounds` 里写上文件名，比如：

```js
sounds: {
  open:  'sounds/open.m4a',     // 点开礼物的那一下
  music: 'sounds/music.mp3',    // 背景音乐
  ...
}
```

| 名字 | 什么时候响 | 建议长度 |
|---|---|---|
| `open` | 点开礼物（空着就用自带的音乐盒声） | 1–4 秒 |
| `voice`, `voice2`, `voice3`… | 拆礼物时的祝福，一个接一个。写成 `['文件', 音量, 第几秒开始]`。现在是：润润（0.45 秒）、小爸（3.8 秒）、外公（9.75 秒）、外婆（15.95 秒） | 想再加一个，就加 `voice5`，开始时间 = 上一个的开始时间 + 它的长度 + 0.4 秒 |
| `burst` | 盖子飞走，花瓣和彩纸撒出来 | 1–3 秒 |
| `unfold` | 纸地图展开 | 1–2 秒，纸张的沙沙声 |
| `music` | 从拆礼物一直到旅程结束（会循环，最后慢慢变小） | 1–3 分钟 |
| `train` | 坐火车的那一段 | 3–4 秒（太长会自动变小声停掉） |
| `plane` | 坐飞机的那一段 | 4–5 秒 |
| `bloom` | 每到一站，花开的那一下 | 不到 1 秒，轻一点的“叮”或风铃 |

- 格式：`.mp3` 或 `.m4a`（iPhone 语音备忘录录的就是 m4a，可以直接用）。
- 每个文件尽量小于 2MB，打开得快。
- 背景音乐要用自己有权使用的（自己录的、免版税的音乐都可以）。
- 妈妈可以在 ⚙️ 设置里把音效关掉。

## 剪掉空白

`voice-birthday`、`birthday-*`、`greet-*` 这几个文件，都是从中文名字的原录音剪出来的：去掉前后的空白，留一点点呼吸，加了很短的淡入淡出，调成一样的音量。原录音没有动。
